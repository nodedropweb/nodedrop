NodeDrop Terminal ist ein modernes Terminal, das neben klassischen Terminal-Funktionen grafische Fähigkeiten wie Web-Browsing, Dateivorschau und KI-Unterstützung bietet. Diese Anleitung hilft dir beim Einstieg.

### Download

NodeDrop Terminal wird über die [Releases-Seite](https://github.com/nodedropweb/nodedrop/releases) verteilt.

<PlatformItem platforms={["windows"]}>

:::note

Die aktuellen Releases sind noch nicht code-signiert. Windows SmartScreen oder Smart App Control kann deshalb warnen oder den Start blockieren.

:::

## Grundkonzepte

### Tabs und Blöcke

- **Tabs**: Wie Browser-Tabs helfen sie, deine Arbeit zu organisieren. Erstelle neue Tabs mit <Kbd k="Cmd:t"/>.
- **Blöcke**: Die Bausteine von Wave. Jeder Block kann ein Terminal, ein Webbrowser, eine Dateivorschau oder ein anderes Widget sein.
- **Layout**: Blöcke können gezogen, abgelegt und in der Größe angepasst werden, um dein ideales Layout zu erstellen.

### Hauptfunktionen

1. **Terminal-Funktionen**

   - Funktioniert mit gängigen Shells (bash, zsh, fish)
   - Unterstützt Standard-Terminal-Funktionen (readline, Steuersequenzen usw.)
   - Enthält den Befehl `ndsh` zur Interaktion mit NodeDrops GUI-Funktionen
   - GPU-beschleunigt (auf den meisten Plattformen)

2. **Grafische Widgets**

   - Dateivorschau (Bilder, Video, Markdown, Code mit Syntax-Highlighting)
   - Webseiten durchsuchen
   - Fragen stellen und KI-Hilfe direkt aus dem Terminal erhalten (mehrere KI-Modelle einrichten)
   - Einfache Systemüberwachungs-Diagramme

3. **Remote-Verbindungen**
   - Einfache SSH-Verbindungen über den Verbindungs-Button <i className="fa-sharp fa-laptop"/>
   - WSL-Integration unter Windows
   - Einheitliche Erfahrung bei lokalen und entfernten Sitzungen

## Schnellstart-Anleitung

1. **Öffne deinen ersten neuen Tab**

   - Neue NodeDrop-Tabs starten mit einem einzelnen Terminal-Block
   - Nutze ihn wie dein gewohntes Terminal
   - Erstelle weitere Terminal-Blöcke mit <Kbd k="Cmd:n"/>

2. **Probiere ein paar grundlegende Befehle aus**

   ```bash
   # Eine Datei oder ein Verzeichnis anzeigen
   ndsh view ~/Documents

   # Eine Webseite öffnen
   ndsh web open github.com

   # KI-Unterstützung erhalten
   ndsh ai -m "how do I find large files in my current directory?" -s
   ```

3. **Passe dein Layout an**

   - Ziehe Block-Kopfzeilen, um sie neu anzuordnen
   - Fahre zwischen Blöcken mit der Maus, um sie in der Größe anzupassen
   - Rechtsklick auf Tab-Kopfzeilen für Hintergrundoptionen
   - Rechtsklick auf Block-Kopfzeilen für blockspezifische Optionen

4. **Mit entfernten Rechnern verbinden**
   - Klicke auf den <i className="fa-sharp fa-laptop"/>-Button
   - Gib `username@hostname` für SSH-Verbindungen ein
   - Oder wähle unter Windows eine WSL-Distribution aus
