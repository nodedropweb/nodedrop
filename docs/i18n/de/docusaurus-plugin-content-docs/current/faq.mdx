# FAQ

### Wie kann ich die Blocknummern sehen?

Die Blocknummern erscheinen, wenn du Strg-Umschalt (Ctrl-Shift) gedrückt hältst (und verschwinden wieder, sobald du die Tastenkombination loslässt).

### Wie stelle ich eine Remote-Verbindung her?

In der Kopfzeile gibt es einen Button. Klicke auf das Symbol <i className="fa-sharp fa-laptop"/> oder <i className="fa-sharp fa-arrow-right-arrow-left"/>
und gib `[user]@[host]` ein, mit dem du dich verbinden möchtest.

### Wie nutze ich unter Windows Git Bash als Standard-Shell?

NodeDrop erkennt Git-Bash-Installationen automatisch und fügt sie zum Verbindungs-Dropdown hinzu. Klicke einfach auf das Symbol <i className="fa-sharp fa-laptop"/> oder <i className="fa-sharp fa-arrow-right-arrow-left"/> in der Block-Kopfzeile und wähle "Git Bash" aus der Liste.

Alternativ kannst du Git Bash manuell als Standard-Shell festlegen, indem du die Konfigurationsvariable `term:localshellpath` auf
den Speicherort der Git-Bash-Datei "bash.exe" setzt. Standardmäßig befindet sie sich unter "C:\Program Files\Git\bin\bash.exe".
Denk daran, dass in JSON Backslashes maskiert werden müssen. Füge dies also zu deiner [settings.json](./config)-Datei hinzu:

```json
"term:localshellpath": "C:\\Program Files\\Git\\bin\\bash.exe"
```

### Kann ich ndsh außerhalb von NodeDrop nutzen?

`ndsh` ist eine interne CLI, um die Kontrolle über NodeDrop auf die Kommandozeile zu erweitern; mehr dazu erfährst du [hier](./ndsh). Um Missbrauch durch andere Anwendungen zu verhindern, benötigt `ndsh` ein von NodeDrop bereitgestelltes Zugriffstoken und funktioniert außerhalb der App nicht.


## Warum warnt mich NodeDrop beim Start vor der ARM64-Übersetzung?

macOS und Windows verfügen beide über Kompatibilitätsschichten, die es x64-Anwendungen erlauben, auf ARM-Rechnern zu laufen. Das hilft, dass mehr Apps auf diesen Systemen laufen, während Entwickler native ARM-Unterstützung für ihre Anwendungen ergänzen. Das geht jedoch mit spürbaren Leistungseinbußen einher.

Für die beste Erfahrung mit NodeDrop wird empfohlen, NodeDrop zu deinstallieren und die Version neu zu installieren, die nativ für deinen Rechner kompiliert wurde. Die richtige Version findest du in unserer [Installationsanleitung](./gettingstarted#installation).

Du kannst diese Warnung deaktivieren, indem du `app:dismissarchitecturewarning=true` in [deiner Konfiguration](./config) setzt.

## Braucht NodeDrop AI Telemetrie oder ein Konto?

Nein. NodeDrop braucht kein Konto und sendet keine Telemetrie. Telemetrie ist standardmäßig aus. Um NodeDrop AI zu nutzen, füge ein eigenes Modell hinzu: Öffne **Einstellungen → NodeDrop-AI-Modi** und wähle **Modell hinzufügen (Assistent)**. Du kannst ein lokales Modell (Ollama, LM Studio, vLLM) oder deinen eigenen API-Schlüssel für Anbieter wie OpenAI, OpenRouter, Groq, Google Gemini oder Azure OpenAI verwenden. Siehe [Lokale Modelle und BYOK](./waveai-modes.mdx).
