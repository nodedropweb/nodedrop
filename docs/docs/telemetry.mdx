## tl;dr

NodeDrop Terminal **does not send telemetry or diagnostics data**. Telemetry is turned off by default and no upload endpoint is configured, so the code that would send usage data does nothing. No Wave cloud service is contacted.

## What this means

- No usage metrics, no diagnostics ping and no crash reports are sent to the developers.
- Automatic updates are disabled and no update feed is configured. Install new versions from the [Releases page](https://github.com/nodedropweb/nodedrop/releases).
- The cloud AI modes of the original Wave Terminal are hidden by default. Use your own models instead, see [NodeDrop AI](./waveai.mdx) and [Local Models and BYOK](./waveai-modes.mdx).
- NodeDrop only connects to what you set up yourself: SSH and WSL connections, the AI providers you add with your own API keys, and the web pages you open in web blocks.

## The `telemetry:enabled` setting

The setting still exists for compatibility and defaults to `false`. Turning it on does not send anything, because no endpoint is configured. You can check or change it with `ndsh setconfig telemetry:enabled=false`.

## Origin

NodeDrop Terminal is a fork of [Wave Terminal](https://github.com/wavetermdev/waveterm). The original project collects opt-out telemetry for its own cloud service. That code path is switched off in NodeDrop.
